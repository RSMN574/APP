**臺灣通** 是一款整合臺灣公共運輸資訊的應用程式，提供公車、捷運、臺鐵、高鐵、航空、YouBike 等交通資訊，目標是讓使用者能透過單一 App 查詢不同交通工具的相關資訊。

本專案目前分為兩種版本，以區分開發測試與正式使用需求。

## 版本說明

- **測試版（Beta）**：提供新功能測試與錯誤排查，功能仍可能變動，且可能存在尚未修正的問題。測試者可回報錯誤與提出建議，協助改善應用程式的穩定性與使用體驗。
- **穩定版（Stable）**：經過測試與問題修正後發布的版本，適合一般使用者下載使用。但仍可能存在尚未發現的問題，並不代表完全沒有錯誤。

## 測試版注意事項

測試版主要用於功能驗證與問題排查，請勿將其視為正式穩定版本。

- 使用前請確認版本來源與發布說明。
- 測試期間可能遇到功能異常、資料錯誤或服務中斷。
- 回報問題時，請盡可能提供發生情境、操作步驟及錯誤訊息。
- 請勿將 API 金鑰、存取權杖、個人資料或其他敏感資訊公開分享。

## 功能介紹

- **公車查詢**：查詢公車路線、站點與到站資訊。
- **捷運查詢**：瀏覽捷運路線、車站及相關資訊。
- **臺鐵與高鐵**：查詢鐵路路線、班次及相關資訊。
- **航空資訊**：查詢機場與航班相關資訊。
- **YouBike**：查詢公共自行車站點與車輛資訊。
- **其他交通服務**：逐步整合停車、交通路況、天氣及電動車充電等資訊。

實際功能依各版本的開發進度與發布內容為準。

## 測試與問題回報

如果使用過程中遇到問題，歡迎透過 GitHub Issues 提交錯誤回報與功能建議，協助改善台灣通。

回報時建議提供：

- 使用的 App 版本
- 裝置型號與 Android 版本
- 問題發生的操作步驟
- 錯誤訊息或相關截圖（請先遮蔽個人及敏感資訊）

## 專案目標

台灣通將持續改善程式架構、資料處理與使用者介面，逐步整合更多公共運輸資訊，並在確保安全性與可維護性的前提下，規劃後續版本發布及開源協作。
